# Data Sources Reference

## AgentSight Monitor SQLite

Location: `~/.agentsight/monitor/monitor-YYYY-Www.db`

### tracked_sessions table

| Column | Type | Description |
|--------|------|-------------|
| id | TEXT | Session UUID |
| display_id | TEXT | Short display identifier |
| agent_type | TEXT | claude, codex, gemini, etc. |
| root_pid | INTEGER | Root process ID |
| first_seen_ms | INTEGER | First observation timestamp (ms) |
| last_seen_ms | INTEGER | Last observation timestamp (ms) |
| command | TEXT | Command line |
| cwd | TEXT | Working directory |
| status | TEXT | running, completed, failed |

### monitor_windows table

| Column | Type | Description |
|--------|------|-------------|
| window_id | INTEGER | Window identifier |
| timestamp_ms | INTEGER | Sample timestamp |
| process_count | INTEGER | Active process count |
| cpu_ms | INTEGER | CPU time in window |
| rss_bytes | INTEGER | Memory usage |
| read_bytes | INTEGER | Disk reads |
| write_bytes | INTEGER | Disk writes |
| file_target_count | INTEGER | Unique file targets |
| network_target_count | INTEGER | Unique network targets |

### Useful queries

Session count by agent type:
```sql
SELECT agent_type, COUNT(*) as sessions
FROM tracked_sessions
GROUP BY agent_type
ORDER BY sessions DESC;
```

Recent sessions:
```sql
SELECT display_id, agent_type, command, cwd,
       datetime(first_seen_ms/1000, 'unixepoch') as started,
       status
FROM tracked_sessions
ORDER BY first_seen_ms DESC
LIMIT 20;
```

## AgentSight Record SQLite

Location: `agentsight-YYYYMMDD-HHMMSS.db` or `agentsight-latest.db`

### sessions table

| Column | Type | Description |
|--------|------|-------------|
| id | TEXT | Session UUID |
| agent_type | TEXT | Agent identifier |
| start_time | INTEGER | Start timestamp (ns since boot) |
| command | TEXT | Command line |
| cwd | TEXT | Working directory |

### llm_calls table

| Column | Type | Description |
|--------|------|-------------|
| id | TEXT | Call UUID |
| session_id | TEXT | Parent session |
| model | TEXT | Model identifier |
| input_tokens | INTEGER | Input token count |
| output_tokens | INTEGER | Output token count |
| cache_read_tokens | INTEGER | Cache read tokens |
| latency_ms | INTEGER | Call latency |

### Useful queries

Token summary by model:
```sql
SELECT model,
       COUNT(*) as calls,
       SUM(input_tokens) as input_tokens,
       SUM(output_tokens) as output_tokens
FROM llm_calls
GROUP BY model
ORDER BY input_tokens DESC;
```

## AgentSight Snapshot JSON

Generated by: `agentsight report export -o snapshot.json`

### Top-level fields

| Field | Type | Description |
|-------|------|-------------|
| summary | object | Source, counts, timestamps |
| token_summary | array | Rows by model with token counts |
| sessions | array | Session metadata |
| process_nodes | array | Process tree |
| audit_events | array | Bounded audit events |
| tool_calls | array | Tool call rows |

## Claude Code Native Logs

Location: `~/.claude/projects/-<path-hash>/sessions/*.jsonl`

Each line is a JSON object with message type, content, timestamps, tool calls.

### Finding sessions

```bash
# List recent session files
find ~/.claude/projects -name "*.jsonl" -mtime -7 -type f

# Count sessions per project
for d in ~/.claude/projects/*/; do
  count=$(find "$d" -name "*.jsonl" -type f | wc -l)
  echo "$count $d"
done | sort -rn | head -10
```

## OpenAI Codex Native Logs

Location: `~/.codex/sessions/`

Session directories with conversation state, tool outputs, file changes.

## OpenTelemetry GenAI Exports

JSON files with spans following the `gen_ai.*` semantic conventions.

### Key attributes

| Attribute | Description |
|-----------|-------------|
| gen_ai.system | AI system (openai, anthropic, etc.) |
| gen_ai.operation.name | chat, completion, etc. |
| gen_ai.request.model | Requested model |
| gen_ai.response.model | Actual model used |
| gen_ai.usage.input_tokens | Input token count |
| gen_ai.usage.output_tokens | Output token count |

## LangSmith Run JSON

Exported runs include:

| Field | Description |
|-------|-------------|
| run_id | Unique run identifier |
| name | Run name |
| run_type | llm, chain, tool, etc. |
| inputs | Input data |
| outputs | Output data |
| total_tokens | Token count |
| latency_ms | Execution time |

## Langfuse Trace Exports

Observation trees with:

| Field | Description |
|-------|-------------|
| trace_id | Trace identifier |
| observations | Array of observations |
| observations[].type | generation, span, event |
| observations[].model | Model used |
| observations[].usage | Token usage object |
