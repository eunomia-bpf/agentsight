# Paper figures

Empirical figures in this directory are copied from the independently reviewed
experiment outputs under `docs/tmp/build-and-evaluate/`.  Their generating
scripts and exact source rows live with those experiment records; TikZ figures
remain in `docs/paper/main.tex` because they are definition schematics rather
than measured results.

The repository includes derived, source-linked CSV rows and the hashes of the
six frozen native-session archives.  The native archives themselves are not
published because they contain prompts and source content; they remain local
inputs rather than paper artifacts.
