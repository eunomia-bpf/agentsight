# Viewing AgentPProf profiles

AgentPProf has no visualization frontend. Each successful invocation writes
exactly one standard `.pb` or `.pb.gz` pprof profile. Use existing
pprof-compatible tools to inspect or visualize it.

## Public fixture

The committed synthetic session is safe to use without reading private local
agent history:

```bash
cargo run --manifest-path agentpprof/Cargo.toml -- \
  --project-root . \
  --project-name agentsight-public-fixture \
  --session-file agentpprof/examples/codex/sessions/2026/06/18/public-agentpprof-fixture.jsonl \
  --tagger regex \
  --no-cache \
  --view operations \
  -o public-fixture.pb.gz
```

This run produces only `public-fixture.pb.gz`. AgentPProf does not write SVG,
HTML, folded stacks, JSON summaries, dashboards, or frontend assets.

## Existing pprof tools

```bash
go tool pprof -top public-fixture.pb.gz
go tool pprof -tags public-fixture.pb.gz
go tool pprof -http=:0 public-fixture.pb.gz
```

The `-http` command starts the standard Go pprof viewer. It is not an
AgentPProf frontend. Other consumers that understand the pprof protobuf may
read the same file directly.

## Views

The selected view controls the sample type in the one pprof file:

| View | Sample weight |
| --- | ---: |
| `operations` | normalized agent operations |
| `tokens` | reported token usage |
| `files` | file effects |
| `network` | network effects |
| `time` | operation duration |

Choose one view per invocation and one output profile per invocation:

```bash
agentpprof --project-root . --view tokens -o tokens.pb.gz
agentpprof --project-root . --view files -o files.pb.gz
```

## Operation stacks and evidence

AgentPProf encodes task, phase, action, object, result, outcome, and source
evidence as pprof stack frames or labels. Query them through standard pprof
commands instead of asking AgentPProf to render a second artifact.

```bash
go tool pprof -top -tagshow='outcome|phase|source_kind' agent.pb.gz
go tool pprof -tags agent.pb.gz
```

Project-specific `--tag-rule`, `--op-map`, `--where`, `--stack`, and
`--stack-rule` options affect the contents of the resulting profile. They do
not add another output format.

The SVG and folded files already committed under `docs/flamegraph/examples/`
are archived examples from an earlier renderer. They are not generated by the
current CLI and must not be used as the current AgentPProf interface.
