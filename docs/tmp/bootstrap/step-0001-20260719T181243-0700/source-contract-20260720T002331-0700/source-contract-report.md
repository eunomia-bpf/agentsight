# Source-Complete Action Evidence Decision

Created: 2026-07-20T00:23:31-07:00
Parent: BOOTSTRAP Step 0001 after terminal B9 Full-HTIR dependency BLOCK
Gate: outer idea decision before a fresh EXPERIMENT_GATE plan
Status: selected; no implementation or supervisor admitted

## Trigger

B9 proved the quiescent workspace capture mechanics but failed its mandatory
Full-HTIR implementation dependency after three reviews. The terminal defects
were not presentation details: a model TraceStep could lack an explicit effect,
and a system effect or implementation anchor could be attached across the wrong
boundary, time, or effective goal. A fourth adapter repair is forbidden and
would preserve the deeper problem that post-hoc views are trying to repair
source evidence whose ownership was never closed at capture time.

## Alternatives

1. **Repair the same HTIR adapter again:** rejected by the three-round terminal
   rule and because more validators do not establish missing source ownership.
2. **Drop Full HTIR:** rejected because HarnessFix is the closest structured
   harness-diagnosis baseline; removing it would weaken the novelty test after a
   failed dependency.
3. **Use only official HarnessFix benchmark traces:** rejected because their
   runtime reads benchmark-specific evaluator paths and command-derived effects,
   and they do not represent the intended coding plus auto-research population.
4. **Make action evidence source-complete before projection:** selected. This
   changes the dependency question from “can an adapter infer a faithful HTIR?”
   to “can the existing native/system capture path close every action with exact
   effect and ownership evidence?”

## Selected Source Contract

This is not a new production IR. `agent-session` remains the native abstraction,
and AgentSight remains the source of observed system effects. The experimental
capture path must retain, for every model/tool/environment/finalization action:

- one canonical source call ID and monotonic action time;
- owning top-level/child session, explicit goal, and boundary interval;
- complete native request, response, role, and execution status;
- exactly one effect closure whose state is `observed`, `no_effect`, or
  `unknown`;
- for `observed`, the complete set of system-backed artifact/state effects and
  their Raw IDs; and
- for `no_effect` or `unknown`, an explicit source/system closure record rather
  than an omitted field or a command-text guess.

The dispatcher cannot capture a boundary while an action or effect closure is
open. A closure must occur no earlier than its action and no later than the
accepted boundary. Its goal/session/boundary must equal the source action's
ownership. Specification anchors must bind to a snapshot from a boundary at
which that specification is effective and to a step whose goal is in the
specification's effective-goal set.

The Full Raw condition receives the native, system, snapshot, evaluator-identity,
and specification records themselves. Full HTIR, OCPM, and Workspace Trajectory
may only project those facts and cite their Raw IDs. No view may repair missing
ownership, infer effects from shell text, or introduce a result/label.

## Why This Is Scientifically Different

The failed B9 dependency evaluated post-hoc baseline construction over a loose
manifest. The next node evaluates source completeness and attribution at action
close time. Its unit is the action/effect closure invariant, and failure occurs
before any structured representation or diagnosis is built. The invariant is
shared by all evidence conditions, so it improves validity without privileging
Workspace Trajectory.

This also matches the system-level project claim more directly: Agent action
intent and system effect are not parallel stories; they are two pieces of one
source-linked action record. It remains compatible with the user's requirement
not to add a second general event abstraction.

## Falsifiable Admission Gate For A Fresh Plan

A fresh dependency plan may use excluded development workloads in coding and
auto-research, but it must fail unless all of the following are independently
recomputed:

1. every retained action has exactly one effect closure, including model actions;
2. every observed effect has a matching AgentSight Raw record and canonical call
   ID; no-effect/unknown is explicit;
3. action, closure, boundary, session, and goal ownership agree, with no open
   action at an accepted boundary;
4. every implementation anchor agrees with an effective specification and a
   same-boundary snapshot/content hash;
5. Full Raw can byte-retrieve every fact used by HTIR, OCPM, and Trajectory; and
6. the same checks pass in both coding and genuine auto-research workspaces.

Only after this new source-completeness plan passes independent review and real
preflight may the project reconsider a frozen prospective registry. No
supervisor model, pathology label, or paper effect is admitted here.
