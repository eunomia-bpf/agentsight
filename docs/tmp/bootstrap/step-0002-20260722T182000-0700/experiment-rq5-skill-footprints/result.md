# RQ5 Result: Source-Explicit Skill And Instruction Footprints

The corrected source path recovers 67 explicit Skill invocations and 1,675
source-attributed Skill Tool actions across the six selected projects.  A
separate native-source checker located all 2,063 included transcript streams
and reconciled all 7,304 Skill/instruction signal rows plus 205,836 adjacent
Tool boundaries without a mismatch.  The independent instruction completeness
arm covers 2,822 high-confidence direct/simple-shell accesses; arbitrary
script bodies and unexpanded shell globs are not claimed complete.

Five exact-context Skill strata meet the minimum of three distinct native root
sessions, but only agentskill-observability-paper contains at least two such
Skills inside one exact project/vendor/model/source-role stratum. Within that
case, median Jensen--Shannon distance is 0.116 for 9 same-Skill pairs and 0.123
for 10 different-Skill pairs.  The difference is -0.007 and the one-sided
exact root-session-block randomization gives p=0.750 over 12 admissible
assignments (four distinct statistic values). This is a negative repeatability
result, not weak evidence for a Skill fingerprint.

The source topology is itself consequential for measurement.  Only 476 of
1,675 attributed actions are contiguously preceded by a matching same-stream
invocation;
the remaining rows can reflect parent-to-child delegation or a missing visible
invocation in the selected stream.  The analysis retains native attribution
at the root-session x Skill unit and does not invent per-invocation episode
boundaries.

Instruction-file reads and mutations are measurable as focal events, including
their immediate next Tool action. Their action composition is normalized
within project because the selected cases differ greatly in size. They are not evidence that a harness was
active, followed, useful, harmful, or causal.  These six author-associated
projects remain selected multi-case evidence, not a population sample.
