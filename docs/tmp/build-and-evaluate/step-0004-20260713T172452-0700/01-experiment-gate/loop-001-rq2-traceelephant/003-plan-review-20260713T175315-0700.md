## Review Protocol

Each round is read-only and independent of the root plan author. Before its
round, the reviewer reads `docs/user-instruction.md` and the current plan, may
inspect only source evidence needed to test the causal contrast, and does not
edit the plan. The root records the complete material findings, responds, and
repairs the current plan before the next fresh reviewer starts. A round blocks
only on a scientific or executability defect that could invalidate the result.

The user explicitly required three to five serial reviews, at least three. This
project-specific instruction overrides the current generic skill's tighter
default. Two initially scheduled fresh agents were interrupted after returning
no verdict; they made no plan edit and do not count as review rounds. The
completed source auditor then reviewed Plan version 0 as Round 1.

## Round 1 — Strong Baseline, Information Boundary, And Exact Metric

**Reviewer role:** independent TraceElephant source and experiment-plan auditor
**Completed:** 2026-07-13T17:53:15-07:00
**Verdict:** **MUST-FIX**

### Finding 1 — Headline raw-action condition is too weak

Plan version 0 used `system -> action`, discarded released component/agent
identity, and coarsened the 17 released tool identities into nine custom
families. AgentProf instead received role, intent, status, and prefix-max
propagation. A favorable result could therefore follow from an intentionally
under-resolved baseline rather than semantic responsibility.

**Required repair:** make the sole headline alternative a source-native raw
stack:

```text
system -> component(agent_name) -> exact normalized raw tool/action identity
```

Apply the same prefix-wise Wilson/max propagation to that stack. Define exact
multi-tool, no-tool, normalization, and precedence rules before scorer access.
The primary contrast becomes adding fixed semantic role/intent/status fields
beyond the strongest raw component/action stack, not beating a nine-bin straw
baseline.

### Finding 2 — Reference outcome can become a method-specific proxy

Using the official correct answer or test status inside the shared released
All-at-Once localizer is scientifically defensible: the TraceElephant paper
defines it as the default published developer-facing scenario and both methods
receive the same resulting one-hit signal. Feeding that reference outcome a
second time into the semantic tagger is not necessary. It lets role, intent, or
status encode answer correctness that the raw baseline does not use.

**Required repair:** retain the official reference outcome only in the shared
localizer. Remove it from semantic tagging and every method-specific operation
field. Name the scope **reference-assisted, failure-annotation-blind
localization** and prohibit a no-reference deployment claim. Do not add a
second no-reference experiment.

### Finding 3 — Score, action, tier, and bootstrap definitions are incomplete

“95% Wilson lower bound” does not fix the formula, `z`, empty-group rule, or
floating score ties. The action field is a vocabulary rather than an extraction
algorithm. The percentile interval lacks an estimator. All can change ordering,
work, and the scientific verdict after targets become visible.

**Required repair:** before coding, add:

- the Wilson formula with `z=1.959963984540054` and exact empty-group handling;
- an exact tier-identity rule that charges the complete equal-score tier;
- raw-action extraction and precedence for source tool calls, multiple calls,
  operation subtypes, and no-tool responses;
- the five bootstrap cell sample sizes, duplicated-trace occurrence handling,
  replicate work denominator, and macro recall denominator; and
- an exact percentile order-statistic rule.

### Finding 4 — Verdict rules conflict

One plan section called an interval crossing zero contradictory, while another
allowed either contradicted or inconclusive based on sign and interval.

**Required repair:** use one exhaustive rule after valid full completion:

```text
SUPPORTED     iff paired delta upper endpoint < 0
CONTRADICTED  iff paired delta lower endpoint > 0
INCONCLUSIVE  otherwise
```

Run status `INVALID` or `INCOMPLETE` remains independent.

### Finding 5 — Canonical frontier and plan disagree on baseline roles

`docs/evaluation.md` called native, independent-step, session, raw-action,
flat, and AgentProf all main comparisons and required AgentProf to beat every
declared main same-information baseline. The plan named raw action as the only
headline and treated the others as controls.

**Required repair:** make the canonical frontier agree with the one-headline
experiment contract: the strengthened component/raw-action stack is the sole
headline baseline; native, independent-step, session, flat, exact-flat,
width-only, and oracle rows are mandatory interpretation controls. Otherwise
the positive criterion must include all former main rows.

### Feasibility judgment

The reviewer found no remaining population or context blocker: uniform
response-only All-at-Once, 220 localizer calls, 405 bounded tag batches, one
model worker, 5,960 terminal operation rows, real AgentProf, exact-flat
identity, and 10,000 cell-stratified paired replicates are executable. The plan
must additionally set explicit localizer output reserve, timeout, retry count,
and prohibit the broken full-to-fallback path.

## Round 2 — Semantic Mechanism, Real Binary Path, And Exact Boundaries

**Reviewer role:** fresh independent causal-contrast and executability auditor
**Completed:** 2026-07-13T18:01:00-07:00
**Verdict:** **MUST-FIX**

### Finding 1 — Semantic benefit remains confounded with refinement capacity

AgentProf adds three partition fields and additional prefix-score opportunities.
The exact-flat row proves algebraic reconstruction and width-only tests leaf
width, but neither asks whether an arbitrary same-topology reassignment would
produce the same gain.

**Required repair:** add one target-blind matched-refinement control that
preserves raw-leaf membership, semantic tuple counts, semantic leaf sizes, and
prefix topology/count opportunities while breaking semantic alignment to
operations and outcomes. Predeclare its mechanism-engagement criterion.

### Finding 2 — The real AgentProf path is not executable as written

Plan version 1 named the binary and stacks but specified only `--version`, not
the exact operation schema, invocations, field encoding, output consumed by
scoring, or the relationship between emitted leaves and hit counts. The raw
headline path was still described partly as a deterministic local grouping.

**Required repair:** run both six-field and three-field primary paths through
the same real binary, specify exact commands and operation files, make scoring
consume emitted leaves, and independently reconstruct and verify both paths.

### Finding 3 — Several exact algorithms remain ambiguous or contradictory

The earlier tag paragraph said `unclear/other` while the retry paragraph said
`unknown/unknown/unclear`. “Valid function call,” tool-log paths, malformed
arguments, trace locality of batches, runtime context enforcement, and zero-hit
Wilson behavior were not fully defined. Evaluating the displayed binary64
Wilson formula for `h=0` can produce tiny size-dependent positive values and
accidental score tiers.

**Required repair:** use one fallback; define exact visible JSON paths and
malformed-entry behavior; prohibit cross-trace batches and adaptive truncation;
assert every exact prompt with the actual tokenizer; and branch
`h == 0 -> +0.0`.

### Finding 4 — The canonical RQ2 frontier still overstates the baseline set

`docs/evaluation.md` still said the proposed profile must beat every fair
same-information baseline even though the reviewed plan had one sole headline
source-native component/raw-action baseline and several interpretation controls.

**Required repair:** make the RQ2 table row state that exact headline contrast
and name the remaining rows as non-superiority controls.
