## Findings

### Current-step invalidators

1. **WRITE violates direct user authority.**
   `docs/paper/main.tex:922-923` foregrounds errors and the framework range:

   > “Errors concentrate … and framework macro-F1 ranges from 0.400 to
   > 0.754…”

   This conflicts with `docs/user-instruction.md:126,130`, which explicitly
   says the paper should not contain negative results. The sentence is
   unnecessary to substantiate the positive aggregate result, weakens the
   AAAI narrative, and should be removed. Scope is already bounded in the
   scope and limitations text.

2. **Source and artifact scope require local correction before closure.**
   The 2,737 labels are publication-derived annotations, but not uniformly
   “human category rows”: the source methodology maps known tools
   automatically and manually inspects remaining actions. The class
   definitions used by the adapter come from the secondary TraceView guide,
   not solely the ASE paper. Moreover, the experiment invokes llama.cpp
   independently; it does not demonstrate an integrated AgentProf CLI
   action-tagging path. The paper and canonical memory must describe this as a
   standalone, named-backend, declared-taxonomy accuracy measurement. No
   inference rerun is needed.

### Material but non-invalidating

- Thirty-nine of 2,737 visible inputs contain an exact gold taxonomy label
  (`Action: Locate`). This defeats the blanket claim that semantic target
  separation is completely clean. However, excluding those rows leaves
  macro-F1 approximately `0.4904` versus `0.0616` for majority, so it does not
  overturn the conclusion. Record the exposure and sensitivity in the
  experiment/evaluation evidence; a rerun is unnecessary.
- The tested population and arithmetic are otherwise sound: all 2,737
  published labels were scored in each of two complete no-cache runs;
  prediction vectors agree exactly; macro-F1 is `0.498425` against `0.060981`,
  with whole-trajectory stratified bootstrap delta CI `[0.380168, 0.494079]`.
- Whole-trajectory bootstrap within frameworks, fixed eight-class support, and
  macro-F1 are appropriate for the imbalance and avoid operation-level
  pseudoreplication.
- Majority is only a no-signal lower-bound control. That is adequate for the
  bounded component claim, not for superiority over existing semantic
  classifiers.
- Public-artifact/model-pretraining contamination cannot be excluded. The
  result must not be generalized to unseen or open-set action taxonomies.

population and a reproducible scorer. It materially strengthens the paper’s
evidence for literal action identity. It does not establish literal phase
accuracy, an integrated product feature, or a new thesis-level contribution.

As currently written, the step is a net mixed change: the positive result
strengthens RQ3, while the reader-facing error sentence weakens the requested
AAAI story. After the local WRITE corrections, it is a clear but bounded
strengthening.
