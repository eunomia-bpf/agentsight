`diagnose authentication` responsibility were selected after viewing the prior

## Fixed responsibility projection

Stock pprof focus on `operation:diagnose_authentication` reproduces the
accepted result exactly:

- 105 operations, 21.47% of the complete task family;
- 2,103,587 tokens, 46.15% of the complete task family;
- 58 operations / 1,283,188 tokens from OpenHands/Claude;
- 47 operations / 820,399 tokens from OpenHands/DeepSeek.

The same 105 source members occupy 105 distinct source calls in the native
hierarchy. Native organization therefore preserves exact evidence but has no
shared responsibility frame under which the two executions fold.

The coarse action hierarchy distributes the fixed responsibility over all six
nontrivial action kinds:

| Coarse action | Operations | Tokens | Share of responsibility tokens |
|---|---:|---:|---:|
| execute | 44 | 829,239 | 39.42% |
| version-control | 20 | 464,038 | 22.06% |
| edit | 19 | 401,247 | 19.07% |
| inspect | 12 | 244,428 | 11.62% |
| search | 9 | 155,397 | 7.39% |
| install | 1 | 9,238 | 0.44% |

No single action-kind branch contains even 40% of the responsibility's token
mass. At the next raw-action level, 102 of 105 members are generically named
`run`; that branch also contains 97 unrelated task-family operations. Thus
coarse action retains what the agent did mechanically, but neither level names
the shared SSH-authentication responsibility.

AgentProf gives those same members one focusable cross-run operation frame
while retaining all 105 call/tool leaves and both source-session labels. The
descriptive distinction is therefore organization, not recovered mass:

- native source answers *which concrete calls contributed*;
- coarse action answers *which generic mechanisms ran*;
- the semantic stack additionally answers *which recurring responsibility
  consumed the resource*, then permits source drilldown.

## Relation to stronger baselines

This case-control materialization does not replace the complete RQ3 automatic
comparison. On all 405 CodeTrace trajectories, Automatic Agent reaches 0.704
B-cubed F1 and 0.394 boundary F1, versus 0.663/0.266 for multi-resolution
recurrence and 0.541 B-cubed F1 for raw-action grouping. Recurrence remains the
stronger no-label population baseline; rerunning it on this post-hoc case
would add no new scientific answer.

## RQ1 consequence

The matched projection strengthens the existing RQ1 case in one precise way:
the 46.15% token bottleneck is not created by changing samples or weights, and
it is not directly named by either source identity or generic action
organization. The accepted semantic operation path supplies that missing
responsibility axis while conserving and retaining the same source evidence.

The paper may report this matched organization contrast. It may not describe
it as independent discovery accuracy, a population effect, or proof that
AgentProf dominates every attribution interface.
