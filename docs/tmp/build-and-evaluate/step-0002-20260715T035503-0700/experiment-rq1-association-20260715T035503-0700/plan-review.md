# RQ1 Experiment Plan Review

Reviewer mode: one fresh independent read-only review

## Round 1 verdict: REPAIR

### Blocking defects

1. The 24-hour retrieval window also defined truth, making later true links
   false nulls. Naturalistic truth needed a wider independent audit horizon,
   randomized score-free packets, independent labels, and exact interval
   denominators.
2. Rank order, confidence mapping, ECE bins, paired decision rule, and baseline
   calibration were underspecified. Balanced accuracy cannot use a Wilson
   interval, and 30/30 or 30 line links cannot meet the frozen lower bounds.
3. A Git-add lifetime could not represent the agent write that precedes a new
   file's first commit. The plan also needed fixed timestamps, traversal,
   rename threshold, merge behavior, and deletion/recreation gap semantics.
4. The private raw directory was not actually ignored, default privacy fields
   and a concrete analysis command were not yet executable.

### Nonblocking findings

RECAP and CLSA were used within their supported scope. The nearest-change
baseline was credible and could genuinely win. Local July 14 records exist for
all three parsers, so the preflight is a real-system path rather than a fixture.

## Root repairs

- Separated the independent seven-day oracle horizon from the 24-hour retrieval
  window; froze event and audit intervals, randomized annotation packets,
  reconciled primary labels, agreement, and disagreement sensitivity.
- Froze lexicographic ranking, evidence/distance confidence bins, Laplace
  calibration, null threshold, ten-bin ECE, paired bootstrap, and a deterministic
  simpler-method selection rule.
- Replaced balanced-accuracy Wilson bounds with per-class Wilson bounds and
  raised minimum support to 50 positive/50 null path pairs and 100 line links.
- Froze committer time, first-parent integration traversal, 50% rename threshold,
  separate merge stratum, pre-birth assignment, and deletion/recreation gaps.
- Added a tracked ignore for `raw/private/`, a default privacy contract, and an
  exact analysis command/path. A single allowed follow-up review is pending.

## Follow-up verdict: APPROVE

The same reviewer confirmed that the independent oracle, ranking/calibration,
sample and interval policy, lifetime/Git semantics, private raw path, privacy
default, and exact commands are now scientifically valid and executable. No
blocking defect remains.

Implementation must make confidence bins mutually exclusive. For Brier score
and ECE, the fixed binary event is whether the reported top candidate belongs
to the independent oracle target set; a null target scores every candidate as
incorrect. These are implementation clarifications, not a plan revision.
