## Current-profile composition

Add only one thin experiment runner. It composes existing artifacts rather than
introducing a new attribution method:

1. read the R114 result, fixed manifest, exported snapshots, and existing
   `effect-lineage.csv` rows;
2. emit one operation per process/file/network effect using ordinary AgentProf
   operation JSONL;
3. copy source-visible effect, process, target, session, and task-category
   fields; assign a task category to an effect only when the existing exact
   lineage row is joined to the task's captured agent operation;
4. keep oracle scope, negative-control identity, and expected counts in the
   scorer state, not in fields used to construct the profile;
5. invoke current `agentpprof` through `--operation-file` with deterministic
   JSON output.

The thin runner may contain conversion, invocation, and scoring glue only. It
may not change R114's task manifest, lineage matching, scope definition,
negative controls, or AgentProf folding logic.

## Complete current-profile views

Construct only three views over the identical operation population:

1. **tag-free/source-effect:** project, effect, process, target;
2. **session-only:** project, session, effect, process, target;
3. **exact-lineage semantic:** project, task category, effect, process, target.

These views reuse the current RQ1 comparison. They are descriptive context;
the independent lineage outcomes below remain primary. Do not add another
stack, ranker, induction mode, cutoff, or view.

## Primary outcomes

Use R114's existing oracle definitions and report:

- scoped attribution precision and recall over in-scope effects;
- negative-control effects observed and falsely joined;
- all joined effects represented exactly once in current AgentProf input;
- exact preservation of total joined-effect mass after semantic folding;
- exact agreement between manifest task-category totals before and after
  profile folding.

The tested hypothesis is supported when all 20 tasks complete, scoped
precision and recall are 100%, zero observed negative-control effects are
joined, every joined effect reaches AgentProf exactly once, and folded task
category mass matches the independently constructed input totals exactly.
Counts may differ from the historical run because real executions differ.

Report the number of session groups and recurring task-category groups to show
that the semantic view reunites correctly attributed responsibility across
runs. Do not use group count as an accuracy outcome.

## Validity checks

- the manifest contains exactly the unchanged 20 task IDs and categories;
- current AgentSight and AgentProf binaries are used;
- every task has one completed capture, export, and lineage result;
- the existing R114 in-scope and negative-control definitions are unchanged;
- scorer-only oracle fields never enter profile stack construction;
- each effect event appears once in the operation population;
- joined, unjoined, in-scope, out-of-scope, and negative counts reconcile;
- the three profiles use identical operation inputs and unit effect weights;
- validity and scientific support are reported separately.

## Required result boundary

A positive result supports exact cross-layer effect attribution for the fixed
20-task real Codex suite and shows that current AgentProf preserves that
attribution while folding repeated task categories across runs. It does not by
itself establish semantic tag correctness, arbitrary-agent capture coverage,
or universal causal attribution.
