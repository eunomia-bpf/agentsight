## Two stages reported separately

### Stage A: existing R114 scoped-lineage result

Use the unchanged R114 aggregate and scorer. Support requires:

- precision at least 98%;
- recall at least 95%;
- zero joined negative-control effects;
- a negative control observed for every task;
- every target task completed.

The report must not call R114 an independent per-effect oracle. The concurrent
marker controls supply the independent false-join check; in-scope membership
and joining both use captured process-family evidence.

### Stage B: current AgentProf preservation

Add one thin experiment runner with only these responsibilities:

1. read the completed R114 result and each existing per-task
   `effect-lineage.csv`;
2. select already joined rows without recomputing lineage, scope, or negative
   controls;
3. convert each joined row exactly once to ordinary operation JSONL, copying
   source-visible effect/process/target/session fields and the task's known
   manifest category;
4. invoke current AgentProf once with deterministic JSON output and stack
   `project,task,effect,process,target`;
5. verify exact input row count, total unit mass, and per-task-category mass
   before and after folding.

Task category is a known run-level field. It is not an AgentProf prediction.
No scorer-only lineage, scope, or negative-control field enters the operation
stack.
