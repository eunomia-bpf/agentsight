## Must-fix 1: R160 boundary

R160 used the predecessor AgentFlame CLI and contains one clean/cached pair. It
is valid prior evidence that the shared tag-cache mechanism eliminates repeated
LLM calls, but it is not repeated performance evidence for the current release
`agentpprof` binary. Plan version 2 states that boundary explicitly.

## Must-fix 2: heterogeneous-workload R-squared

The four public inputs are heterogeneous rather than nested samples. A hard
R-squared threshold could reject a valid and useful cost curve merely because
stack cardinality and content differ. Plan version 2 retains monotonicity,
linear fit, milliseconds per operation, unique stacks, and output bytes as
descriptive predictability evidence, while only the largest complete union's
predeclared time/memory bounds determine practical scaling over the tested
range.

## Disposition

Both changes are local scientific-calibration fixes. They do not change RQ4,
the tested current-binary matrix, the positive research direction, or the
reuse/simplicity boundary. Proceed to serial plan review round 2.
