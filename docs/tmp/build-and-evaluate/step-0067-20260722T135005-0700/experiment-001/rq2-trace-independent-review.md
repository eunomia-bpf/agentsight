### Construction/score boundary

The data flow is target-separated:

1. packets, annotations, N0 paths, N1 recurrence assignments, A0 paths, and A1
   paths are constructed;
2. all four complete paths are written to `fixed-groups.jsonl`;
3. only then does `load_signals_after_groups()` open
   `operations/projection.jsonl` and `scorer/targets.jsonl`.

The Trace annotation constructor has no scorer/root argument and no read of a
projection, target, response-localizer, or historical group file. Its mentions
of forbidden field names reject such keys rather than consume them. Therefore
the target step and released localizer output were not used to choose A0/A1
boundaries or names.

This evidence supports a **deterministic, Agent-authored source-only semantic
constructor**. Because the stored annotations are exactly generated by the
benchmark-aware Python helper, the artifacts do not by themselves demonstrate
an online general LLM backend independently reading every session. Descriptions
should say what ran; “Codex directly returned every stored path” would require
separate raw backend outputs that are not present here.

### N1 product-contract discrepancy

N1's fixed/scored group is `(task_family, induced_motif)`, as required by the
plan's source-context wording. Its persisted command instead runs recurrence
directly with `--stack operation`; it has no mark file and does not include the
task-family/project frame. This explains 329 scored paths versus 253 pprof
stacks.

The discrepancy does not invalidate the reported N1 MAP: the 329 scored paths
are complete, target-blind, and reproducible. It does mean the saved N1 profile
is not the same grouping that was scored and does not yet satisfy the plan's
claim that all methods are serialized under a common source-native product
context. Replaying the already fixed `(task_family, motif)` assignments through
the common marked-profile path is the required repair; no regrouping or new
scientific run is needed.

As a sensitivity check, scoring the motif-only grouping represented by the
current N1 pprof yields MAP 0.154510 instead of 0.129695. A0 and A1 still exceed
that alternative: their deltas are +0.039585 and +0.097416, with stratified
paired 95% intervals `[0.003607, 0.075943]` and
`[0.055537, 0.140332]`, respectively. Thus the mismatch does not reverse the
main recurrence comparison, but it must not remain hidden.

## Independent MAP reproduction

I independently rebuilt the metric without calling the scorer's `score()` or
`scores_for_method()` functions:

1. read all fixed paths;
2. opened the authoritative projection and target rows;
3. counted released localizer hits for every prefix;
4. recomputed the exact-zero Wilson lower bound for each prefix;
5. assigned each operation the maximum score over its path prefixes;
6. computed `sklearn.metrics.average_precision_score` separately for each of
   the 220 one-target queries;
7. took the arithmetic mean of query AP.

The authoritative population has 115 valid localizer-hit operations, of which
35 equal the official mistake step (35/220 = 0.159091), matching the historical
TraceElephant report.

The recomputed per-query AP values match `per-query.jsonl` with maximum
absolute difference exactly zero.

| Method | Independently recomputed MAP |
|---|---:|
| N1 recurrence | 0.1296948341 |
| A0 automatic Agent | 0.1940943228 |
| N0 native tree | 0.2301683213 |
| Historical AgentProf | 0.2301683213 |
| A1 source-preserving Agent | **0.2519262823** |

Historical AgentProf's textual paths are hex encoded while N0 uses decoded
strings. Nevertheless, their partitions are bijective at every one of the six
prefix depths: 3, 20, 52, 145, 308, and 435 prefixes. Their 220 per-query AP
values are identical, giving exact reproduction of the registered historical
MAP `0.23016832132386486`, well within the required `1e-12` tolerance.

## Representative source-level cases

### `django__django-11299`: useful diagnosis, not successful target ranking

This real SWE-Agent trace contains 94 operations and 66 sparse marks. The
source-only hierarchy exposes a clear failure pattern:

- 57/94 operations are `Repair software regression -> Reproduce issue ->
  Repair reproducer harness`;
- that operation returns in 31 separate spans;
- 32 operations run the reproducer;
- the trace ends in another harness repair, with no source-visible verification,
  implementation completion, or submission.

The stock A1 pprof can select this exact trace through its `source_session`
label. The filtered profile conserves all 94 operations and shows 69
`str_replace_editor` leaves and 25 `bash` leaves beneath the semantic paths.
This is genuinely useful to a user: the trace spent almost all work repeatedly
repairing and rerunning its test harness rather than progressing to a verified
Django fix.

The benchmark target is step 22, but this query has no released localizer hit.
Its AP is 0.028571 for N0 and 0.010638 for N1/A0/A1. Therefore this case supports
the hierarchy's diagnostic readability, not the claim that A1 localized the
official mistake.

### Captain-Agent GAIA task 155: why the source suffix matters

For `captain-runs-gaia/gaia_task_155_gpt-4o_f1hwkqk29ln0`, the official target
and released localizer hit are both step 3. A0 labels both an orchestrator plan
and the information expert's start as `Acquire evidence -> Plan evidence
retrieval`, collapsing source-distinct work. A1 appends `act ->
informationextraction_expert` to the target while the orchestrator keeps
`plan -> orchestrator`. AP rises from 0.043478 (A0) and 0.125000 (N0) to
1.000000 (A1). This is a direct, source-grounded example of the A1 mechanism.

### `django__django-11490`: useful semantic generalization

The target source action is a `str_replace_editor` change to Django's SQL
compiler. A0 correctly places it under `Change implementation -> Implement
fix`, while neighboring steps remain reproducer work and verification. AP is
1.000000 for A0/A1 versus 0.030303 for N0 and 0.026316 for N1. The trace has no
within-query localizer hit, so the score comes from cross-trace grouping rather
than reading its target. This is a positive semantic-grouping example, with the
within-population interpretation noted below.

### Captain-Agent AssistantBench task 29: counterexample to dominance

For the season-pass calculation task, no operation has a released localizer
hit. N0 ranks the official step first (AP 1.000000), while A0 and A1 both obtain
0.100000. The semantic hierarchy is readable, but its broad `Execute analysis
step` grouping does not discriminate the official mistake. This case, together
with the family table, is why the result cannot support universal semantic
superiority.

## Metric and interpretation boundaries

1. The primary metric is standard per-query AP/MAP, and the historical value
   reproduces exactly. No custom top-k or reader-budget metric is used.
2. Prefix hit rates are estimated on this complete registered population,
   including each query's released localizer output. This is the unchanged
   historical protocol and is applied identically to all methods; it is not a
   held-out generalization estimate.
3. A1 was introduced after A0 exposed a product-contract mismatch. Its paths
   are still target-blind and exactly source-derived, but its A1-A0 comparison
   is a post-A0 contract correction rather than an originally predeclared
   independent method.
4. The absolute MAP values remain modest, and the underlying localizer is
   exactly correct on 35/220 traces. The result evaluates how each hierarchy
   propagates that fixed signal; it does not demonstrate a universally accurate
   problem detector.
5. The source-filtered pprof cases demonstrate inspectable task decomposition,
   repeated work, and missing completion. They do not measure human time saved
   or causal debugging success.

## Final judgment

The TraceElephant numerical result is trustworthy and source/target separation
is intact. It gives a valuable, nontrivial answer: semantic paths alone lose to
the native tree on this population, while semantic paths plus the original
source-call suffix recover that loss, clearly beat recurrence, and yield the
best point MAP. The remaining evidence does not establish superiority over the
native-tree/historical baseline. The result is supporting RQ2 evidence, and the
method-matrix node remains incomplete only because N1's saved pprof has not yet
been replayed as the exact grouping that was scored.
