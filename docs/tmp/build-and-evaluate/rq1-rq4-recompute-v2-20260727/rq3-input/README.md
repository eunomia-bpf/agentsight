# RQ3 status-preserving access input

`rq4-accesses.csv` is named for the fixed `plot_rq5.py --rq4-root` interface,
but it is independently rebuilt from the repaired RQ1 event exports.  It
retains path-resolved actions from both `ok` and `observed` events so RQ3's
declared native-status sensitivity is not collapsed to confirmed effects.
RQ4's own confirmed-effect access ledger remains under `rq4/raw/`.
