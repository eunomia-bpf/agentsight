## Semantic Operation

operationalization of the already registered definition: a semantic frame is a
temporally extended goal capable of owning multiple lower-level operations.
It is not a depth cap: a depth-20 frame with support two remains, while a
depth-1 singleton contracts. Support two is the minimum multi-action evidence,
was selected before any stage score, and is not swept or calibrated.

Contraction conserves every operation by assigning it to the nearest retained
ancestor. Child support cannot exceed parent support, so the rule is equivalent
to bottom-up removal of transient leaves and chains. On retained source-only
paths, only 17/20,254 operations fall to the synthetic root; the root therefore
provides structural completeness rather than collapsing every trajectory.

adjacent-boundary F1 secondary, named multi-resolution task bootstrap, and the
same four baselines. Flat stages validate only effective leaf partitions, not
