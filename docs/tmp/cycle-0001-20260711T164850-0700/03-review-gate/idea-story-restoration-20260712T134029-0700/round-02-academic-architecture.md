## Academic Architecture

The challenged belief should not be that execution trees are useless. It is
that an emitted execution hierarchy is a neutral or universally correct index
for aggregation. Semantic grouping is not automatically correct either. A
token profile, retry profile, unsafe-effect profile, and before/after difference
may have different structural support. Measure and hierarchy jointly define
the profile.

This yields three plain requirements:

1. Reprojection retains independently verifiable source identity and drilldown.
2. Every profile declares selected operations, additive measure, and hierarchy,
   assigns operations consistently, and conserves the measure.
3. Alternative profiles over identical evidence are compared under matched
   information and effort, and their groups correspond to meaningful decisions.

Target-label isolation and matched rankers are evaluation validity rules rather
than new system requirements. The current three RQs remain the right academic
architecture: RQ1 tests fidelity and comparability; RQ2 tests consequential
analytical value; RQ3 tests transfer and limits. No fourth RQ is needed.

The three contributions should be plain: the profiling position and two-object
model; AgentProf as an evidence-preserving profiler; and an empirical account
of when profile structures change real decisions, including negative cases.

## System Direction

AgentProf should not grow another subsystem before decisive evidence. The
ingestion path should retain stable operation identity, trajectory identity,
native parent/path data, visible fields, and additive measures. One query
selects a cohort, measure, and stack constructor; the same terminal operations
are then materialized as flat, genuine native, and one predeclared semantic
profile. Induction, ranking, import, and differential comparison remain
supporting mechanisms.

Paired cohorts are the natural next workload: compare two releases, models,
prompts, or policies on the same real tasks and attribute a directly measured
change. This restores the original profiler identity without inventing a new
object or claiming automatic hierarchy selection.

## Unexpected Directions And Missing Question

The discussant proposed treating profile disagreement as useful uncertainty,
evaluating the unit of intervention rather than only the unit of inspection,
and measuring the shape of a change—recurrence, native-tree fragmentation,
semantic concentration, and sparsity—without naming a new taxonomy.

The important missing question is: **what information may choose the hierarchy
before the target result is inspected?** If the target regression guides fields,
depth, mapping, or ranking, the comparison can overfit without using explicit
labels. Hierarchy selection must therefore be fixed on development evidence or
derived prospectively from the question.

## Constraints And Next Evidence

The proposal preserves the user's three fixed RQs, two core abstractions, broad
scope, real-benchmark preference, complete runs, admitted negative results, and
the read-only submodule. It does not introduce a selector, graph, contract, or
new named layer. The next source must provide complete trajectories, paired
cohorts, an operation-level additive measure, a genuine native hierarchy, and
an independently meaningful decision. If no released corpus qualifies, run a
published benchmark with AgentSight instrumentation rather than inventing a
toy trace.
