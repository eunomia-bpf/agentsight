## Protections In The Current Skills

Current `iter-refine-ideas` now states that:

- reviewers are discussants, not attackers or editors;
- novelty cannot come from layers, contracts, or taxonomies;
- supporting mechanisms cannot become the central contribution merely to
  answer an objection;
- Round 1 recovers the largest, most interesting, most faithful idea;
- the process does not iterate until reviewers run out of objections.

Current `research-experiment-design` now requires one explicit RQ, one complete
experiment, and one concise plan; only defects that invalidate the result or
make execution impossible block; optional polish does not; a valid negative
result returns to idea refinement.

The current orchestrator reserves full adversarial paper review for milestone
acceptance, while current literature and review skills explicitly preserve or
expand the ambitious position. These changes directly address the old causal
path.

## Ranked Residual Risks

### Must — contaminated project state

The current paper treats stable semantic scope as the scientific unit and
places an unimplemented identity labeler, scope-tree contract, navigator, and
bundle control in the core argument. RQ1 is partial; RQ2--RQ4 remain unanswered.
A fresh agent can therefore follow the current skills correctly yet preserve a
proposal-like paper because the starting state already declares the accumulated
mechanisms canonical.

### Must — revision-1 resume ambiguity

`loop-rq2-01` ends after review without preflight. If it is not marked
superseded, a resume path can reasonably treat it as the innermost unfinished
node and continue repairing the 470-line plan.

### Must — ambiguity in what ambitious contribution must be protected

The project must distinguish the protected scientific objective from later
mechanisms. Protect semantic profiling, the operation-plus-operation-stack
center, and the cross-run/multi-resolution ambition. Do not protect stable
identity, navigator, bundle control, or any reviewer defense merely because it
appeared in a prior contribution list. “Bigger” means larger explanatory scope
and scientific consequence, not more concepts, components, baselines, or RQs.

### Should — review/literature requirement accretion

Milestone review legitimately searches every contribution and RQ for closest
work, contradictions, baselines, protocols, and real assets. If invoked during
idea recovery, those findings can again become simultaneous requirements.
Classify each as novelty threat, mandatory baseline, optional robustness, or
future branch. Do not run `iter-review-critique` as an idea attack loop.

### Should — experiment-plan expansion

The current experiment skill no longer fixes a review count, but review still
continues until no blocking defect remains. Locally apply this boundary: a
suggestion that introduces a new core mechanism, primary outcome, benchmark
family, or independent scientific hypothesis is not a repair to the current
plan; it returns to idea synthesis or becomes a future experiment.

### Consider — detailed reports becoming checker theater

Node/gate/cycle reports preserve useful provenance, but outer audit must only
ask whether the node answered its declared question, raw evidence supports the
report, the user objective was preserved, and the declared scope completed.
Zero optional reviewer suggestions is not a transition criterion.
